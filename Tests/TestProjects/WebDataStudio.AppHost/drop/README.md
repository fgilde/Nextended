# Dropped files

This folder is mounted into the studio as a storage connection (`DROP`). Everything here is browsable
in the tree, previewable in the structure panel, and — where a reader understands it — queryable as a
table.

* `people.csv`, `orders.ndjson` — open them as tables, or make real tables out of them.
* `settings.json` — one long line, indented by the preview.
* `handbook.pdf`, `logo.png` — shown where they lie rather than downloaded to be looked at.
* `monthly/` — three files with the same columns: query the whole prefix as one table.
