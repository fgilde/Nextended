## Installation

```bash
dotnet add package Nextended.Aspire.Hosting.Grafana
```

## Was das Paket macht

Grafana, Prometheus, Loki, Tempo, Promtail, cAdvisor, postgres_exporter und den OpenTelemetry Collector als kombinierbare Ressourcen mit automatisch bereitgestellten Datenquellen.
