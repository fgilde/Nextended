```bash
dotnet add package Nextended.Aspire.Hosting.Php
```

PHP-Endpunkte im Aspire-Stack betreiben — ein docroot-Ordner oder ein einzelnes Router-Skript über PHPs eingebauten Webserver, mit php.ini-Einstellungen als Fluent-Optionen.
